🌸Tentang Saya

Halo, saya Yasmin Thahirah. Saya suka mengeksplor hal-hal seputar makeup, memasak, desain, dan dunia digital. Di web ini saya berbagi berbagai inspirasi dari Pinterest moodboard, mulai dari ide makeup, outfit, sampai resep makanan, serta berbagai link produk yang saya gunakan atau saya sukai.

Saya adalah mahasiswi Teknik Informatika di Universitas Jabal Ghafur, Pidie, Aceh. Saya sedang belajar dan mengembangkan keterampilan di bidang teknologi, khususnya web dan desain, sambil tetap menyalurkan hobi saya di dunia memasak. Di sini juga saya menampilkan beberapa project yang saya kerjakan sebagai bentuk latihan dan pengembangan diri. Web ini menjadi tempat saya menuangkan ide, inspirasi, dan hasil karya saya.
